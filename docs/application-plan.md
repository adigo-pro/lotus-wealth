# Lotus Wealth Application Plan

Lotus Wealth is a budgeting app for everyday spending, monthly cashflow, savings goals, recurring bills, and long-term wealth planning.

## Implemented

- Lotus-branded Lotus Wealth UI and favicon.
- Account sign-in and saved budget plans.
- Budget profiles, expenses, goals, recurring bills, and transactions.
- Cashflow and roadmap views so the app is more than a one-page calculator.

## Next Build Phases

1. Accounts: add profile settings, password recovery, and account deletion/export.
2. Budgeting: add monthly budgets, category caps, recurring bill reminders, and transaction review flows.
3. Goals: add deadlines, contribution schedules, savings history, and emergency fund health checks.
4. Insights: add trend charts, subscription audits, no-buy challenges, and monthly reports.
5. Imports: add transaction uploads and guided cleanup for messy spending history.
6. Polish: add reminders, empty states, mobile refinements, and calmer monthly review flows.
